# Little Shelf design

Operate mode. A library reading desk: warm paper, pine ink, small category tabs and an uncluttered reading area. The content is the visual material. System serif is used only for the product headline and entry titles; controls use the system sans. No external assets or animated entrances.

Tokens: paper#f5f2e9, surface#fffdf7, ink#24372f, muted#626e63, line#dcded2, pine#315743, clay#9b583d, yellow#eee2b6. Body14/22px, title46/50px on desktop and34/38px on mobile, entry title23/28px. Spacing8/12/16/24/32/48px. Cards use a quiet1px line and8px radius. The pin, edit and archive actions stay in the same position on every entry.

Desktop: compact brand/navigation rail, left-aligned title and new-entry action, category filters/search, two-column reading cards. Mobile: stacked brand and controls, single-column cards, full-width forms. Empty and error states include their next action. Changes are saved explicitly. Filtering and search stay local so idle applications can sleep.
