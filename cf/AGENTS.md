This is the Cloudflare plane of M1, positioned by [ADR 0041](../docs/adr/0041-cloudflare-m1-plane.md) and structured by [ADR 0042](../docs/adr/0042-cloudflare-edition.md). Its native interfaces live in `docs/app-contract.md`, and its acceptance gates live in `docs/acceptance.md`. The Docker and Kubernetes planes share no code with it. No tracked file names a real deployment's domain, account or resource ID.

Use native Worker bindings and built-ins. D1 owns identity/directory state. One AppCell owns each application's lifecycle and data. Store all platform app metadata in hidden Durable Object KV; application SQL owns the SQL namespace. Every storage operation checks the execution generation synchronously before mutation. No guest receives account credentials. R2 object bytes transfer directly between the client and R2.

Run `npm run check`, `npm test`, and relevant real Cloudflare acceptance after changes. Tests must name a row in `docs/acceptance.md`. A local engine test does not establish cloud Container, DNS, certificate, browser, or TURN behavior. Keep credentials outside tracked files. Do not report an advertised operation as complete from a placeholder result.
