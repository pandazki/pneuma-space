# ADR 0049：CF 首次应用的交接分两步

状态：接受。2026-11-27。修订 [ADR 0043](0043-cloudflare-first-application.md) 的“一条指令”和“复制指令包含凭据”。

## 背景

ADR 0043 让创建应用页生成一条含发布 token 的指令，由用户贴给编程工具执行。开发者反馈：token 因此进入聊天记录，有凭据规则的 agent 也不会替用户执行这一步。

## 决定

创建应用页生成 token 后给出两步。第一步是用户自己在终端运行的 `init` 命令，token 经标准输入写入新项目目录里的私有凭据文件。第二步是一句交给在该目录中打开的编程工具的话，不含 token：读 AGENTS.md，在该目录运行项目自带 CLI 的 `start`，立即发布并测量请求用时，再报告应用地址、统计链接和用时。首次运行因此和原来一样快；`npm run bench` 仍是之后单独验证自然休眠与唤醒的命令。页面照旧跟踪发布进展。

不新增接口、一次性代码或表结构。浏览器授权登录同样能让 token 不经过聊天，但需要新的授权流程，这里不做。
