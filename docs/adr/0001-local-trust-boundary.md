# ADR 0001：可信单机原型与演进边界

状态：**M1 沿用**。信任边界的完整表述在 `REQUIREMENTS.md`。

背景：先验证个人本地运行，同时为组织身份与未来云服务保留演进空间。

决定：使用单机 Docker Compose 与本机管理接口，应用镜像和操作员均须可信。网关访问 Docker socket，应用共享网络；只绑定回环接口不等于身份认证。企业 SSO、可信身份传播和租户隔离不在原型中。

后果：本地试验部署简单，不能安全承载不可信代码、跨组织租户或公网流量。后续必须单独设计计算、网络、控制面和数据面隔离及身份鉴权。证据：`REQUIREMENTS.md` 的信任边界、`tests/compose_smoke.py`。
