# 0043：CF 首次应用体验

状态：接受。2026-11-14，写于未公开的分支，编号 0034；并入主干时改为 0043。

用户要求从创建 token 出发，用一条指令让编程工具完成首个应用、上线、自然休眠与恢复验证，再回控制台查看访问统计。用户不应先阅读文档或选择底层能力。

## 决定

租户控制台以“创建应用”为主要入口，生成仅含 read、publish、invoke 的租户凭据。它不获得平台管理、成员管理或清除权限。复制指令包含凭据，页面明确说明其用途和到期时间，凭据只留在当前页面内存；重新打开页面可生成并撤销旧凭据。

服务自己的静态资源发布一个可由 npx 下载的独立 CLI 包，包名包含内容散列。它使用 Node 内置模块，通过既有公开接口创建、直传发布和观测应用，不依赖平台源码、Cloudflare 账户或本机服务。只分发客户端与示例。

脚手架在新目录内安装 AGENTS.md 与多平台可发现的项目级 skill。编程工具是客户端使用者，不是平台实体、运行时或能力；示例与指令留在 templates 下。按用户此次要求，控制台可以直接说明 agent 的使用入口。该措辞不改变原平台模型边界。

默认指令完成一个可交互、有持久数据的示例。它输出应用和控制台统计的直接链接。后续编辑通过同一目录内的 CLI 再发布。仅应用目录进入发布包，凭据、skill 和本机配置均不上传；本机凭据按 0600 保存并加入忽略规则。

验证记录真实端到端耗时，不把网络耗时称作容器启动耗时。不调用强制休眠来代替自动回收：停止应用流量，查询控制面直到自然休眠，再访问并确认新的启动身份和持久数据。记录开始与结束时的实际请求、唤醒和休眠计数。其他流量阻止休眠时明确报告尚未验证。

界面只承诺按需运行和数据保留，不把停止容器推导为整项 SaaS 总成本为零。范围和成功条件见 [CF 验收](../../cf/docs/acceptance.md)。
