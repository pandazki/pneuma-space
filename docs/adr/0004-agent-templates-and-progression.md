# ADR 0004：把 Agent 视为平台使用者

状态：**方向已确定；模板和工具协议为暂定假设**。

决定：现有 Agent 或人都可读取模板说明、修改业务、构建和发布，不绑定特定 Agent 产品。独立 Agent 只读指南后做出问卷，但暴露了复制模板、依赖声明、数据库和宿主适配等缺口；记录见 `prototype/01-agent-app/`。指南已补充如何复制模板，其他问题留待设计。

未来方向：按需提供可版本化模板与开发指南，并设计自动初始化、企业身份及宿主上下文注入。Kubernetes、多租户与托管云是后续可能路径，尚无实现、服务承诺或成本数据，不要求当前原型一键转换为云服务。
