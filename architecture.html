PneumaSpace’s gateway is a single Node.js LTS program written in TypeScript that Node executes directly with zero runtime npm dependencies (ADR 0012, AC-STORE-8). Every table in the platform store has exactly one owning component that writes to it; every instance state transition happens via lock-free conditional update (CAS) on (runtime, state, epoch); and every wake goes through a single verb: Runtime.acquire().PneumaSpace 网关是一个由 Node.js LTS 原生直接执行的 TypeScript 程序，零运行时 npm 依赖（ADR 0012, AC-STORE-8）。平台库中的每一张表都有且仅有一个唯一写者组件；每一次实例状态转换都通过 (runtime, state, epoch) 上的无全局锁条件更新（CAS）完成；每一次唤醒无论是来自 HTTP、WebSocket 还是定时触发器，都只经过同一个动词：Runtime.acquire()。

1. One Paragraph Domain Model (DESIGN.md §1.1)1. 一段话读懂领域模型 (DESIGN.md §1.1)

DESIGN.md:L7-L10 gateway/src/model.ts:L139-L250

App is a name, and the name is the address. Every publish produces an immutable Release: an image (absent for static sites and isolates), a Manifest, and a Bundle (the static directory or isolate code archive). The Manifest declares Capabilities. Each resource capability has a Provider that provisions a backend Resource recorded as a Binding (one row per App, kind, and Provider, with state active | suspended). Injection (environment variables, storage mounts, and reachable service labels) is derived on the fly from the current Release’s active Bindings when creating an instance and is never stored. An Instance is the running process (Docker container, Kubernetes Pod, or worker thread inside a runner) of the current Release, kept alive only while holding a Lease (request | channel | trigger). A Trigger is a named entry point the platform calls on the app; each invocation is a durable Delivery row. A Principal is resolved by the IdentityProvider and injected as HTTP headers. Policy holds operator tunables. Tenant is the ownership, quota, usage, and audit boundary for Apps; Users belong to Tenants via Memberships (admin | member), and Tokens belong to a Tenant. There are no application archetypes and no Agents in the platform model.App 是一个名字，名字就是地址。每次发布产生一个不可变的 Release：镜像（静态站点和 Isolate 没有）、Manifest 清单、以及 Bundle（静态文件包或 Isolate 代码包）。Manifest 声明 Capability（能力）。resource 类能力由其 Provider 在后端创建 Resource，平台记为 Binding（每 App、每 kind、每 Provider 一条，带 active / suspended 状态）。Injection（环境变量、存储挂载与可达服务标签）由当前 Release 的 active Binding 在实例创建时即时推导，从不落库存储。Instance 是当前 Release 的运行实例（容器、Pod 或 runner 里的 worker 线程），只在持有 Lease（request / channel / trigger）时保持运行。Trigger 是平台调用应用的入口，每次调用是一条持久化的 Delivery。Principal 由 IdentityProvider 解析并以请求头注入。Policy 是运营者策略。Tenant 是应用的归属、配额、统计与审计边界；User 经 Membership 以 admin 或 member 属于租户，Token 也属于租户。平台模型里没有应用类型，也没有 Agent。

6. Zero-Dependency Wire Protocol Clients Built Into the Gateway6. 网关内置的五大零依赖线协议客户端

Why does package.json have zero dependencies? Because the gateway implements the exact subset of each infrastructure wire protocol it needs using Node.js built-in modules (node:net, node:tls, node:http, node:https, node:crypto, node:sqlite).为什么根目录 package.json 的 dependencies 为空（AC-STORE-8）？因为网关仅使用 Node.js 内置模块，自己实现了与五大底层基础设施通信所需的精确线协议客户端。
