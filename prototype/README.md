# 原型验证索引

这里保存三个相互独立的验证视角及一次新的独立 Agent 复验，均为 prototype/demo，不代表生产能力。

1. [独立 Agent 问卷应用](01-agent-app/)：独立 Agent 阅读模板指南后开发真实问卷；包括其原始卡点记录、应用代码、单元测试及真实网关的独立集成测试。
2. [数据库语义](02-storage/)：相同订单业务接口在 SQLite 与临时 PostgreSQL 上验证参数化 SQL、多记录事务、过滤、聚合、约束和并发；明确方言与隔离边界。
3. [有界冷应用实验](03-cold-apps/)：最多 24 个冷应用、3 个活动应用的受限测试，保存修复前后的原始采样和注意事项。

4. [独立 Agent 再次开发](04-agent-recheck/)：无父会话历史的 Agent 从整理后指南构建任务清单，并在隔离网关中实际发布、闲置和唤醒；保留可分享的成功运行记录。

每个目录的 README 包含执行命令、观察与限制。根目录的 [需求](../REQUIREMENTS.md)、[总体设计](../DESIGN.md) 与 [ADR](../docs/adr/) 记录产品意图与原型决策。
